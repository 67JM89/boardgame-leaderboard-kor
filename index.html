리더보드 정렬 기준 (Tier Points 우선)
1순위 Tier Points = 누적 승점 + 누적 감점 · 2순위 총 승점 · 3순위 승리 횟수 · 4순위 게임 수 · 5순위 총 감점 (적을수록 유리)
💡
Tier vs Reward — 헷갈리지 마세요
Tier Points = 게임 실력 점수 (순위 결정). 누적 승점 + 누적 감점만 반영.
Reward Points = 교환 가능 포인트 (지갑). 출석 보너스 + / 사용·교환 −. 교환해도 순위 안 떨어집니다.

🐱 Exploding Kittens 고양이게임

👥 2~5인⏱️ 약 15분🎯 쉬움
🎯 목표폭탄 고양이 카드를 피해 끝까지 살아남기.
🔄 진행 방식
  1. 내 차례에 원하는 만큼 액션 카드를 낸다(미리보기·넘기기·훔치기 등).
  2. 차례 종료 시 덱에서 카드 1장을 뽑는다.
  3. 뽑은 게 폭탄 고양이면 탈락 — 단 해체(Defuse) 카드가 있으면 폭탄을 덱 아무 곳에나 몰래 꽂고 생존.
🏆 승리 조건마지막까지 살아남은 1명이 승리.
💡 해체 카드는 아껴두고, '미리보기'로 폭탄 위치를 파악한 뒤 '넘기기'로 위기를 넘기세요.

🌙 One Night Ultimate Werewolf 원나잇 웨어울프

👥 3~10인⏱️ 약 10분🎯 쉬움
🎯 목표마을팀은 늑대인간을 찾고, 늑대팀은 정체를 숨기기.
🔄 진행 방식
  1. 각자 역할 카드를 받고 밤이 된다(앱 음성으로 진행, 진행자 불필요).
  2. 밤에 역할 순서대로 눈을 떠 능력 사용(늑대끼리 확인, 점쟁이는 카드 확인 등).
  3. 낮이 되면 딱 한 번의 토론 후, 다 같이 한 명을 지목해 처형.
🏆 승리 조건처형된 사람 중 늑대가 있으면 마을팀 승, 없으면 늑대팀 승.
💡 밤 진행이 단 1회라 심리전이 전부입니다. 내 역할을 당당히 주장하되, 밤에 카드가 바뀌었을 수 있으니 맹신은 금물.

🌮 Taco Cat Goat Cheese Pizza 타코캣

👥 2~8인⏱️ 약 15분🎯 쉬움
🎯 목표손패를 가장 먼저 모두 털어내기(순발력 게임).
🔄 진행 방식
  1. 돌아가며 카드를 뒤집으며 "타코-캣-고트-치즈-피자"를 순서대로 외친다.
  2. 외친 단어와 뒤집은 그림이 일치하면 모두 재빨리 카드 더미에 손을 얹는다.
  3. 가장 늦게 손을 얹은 사람이 쌓인 카드를 전부 가져간다.
🏆 승리 조건손패를 먼저 다 없앤 사람이 승리(고릴라·나르왈 등 특수 카드는 정해진 동작 먼저 하기).
💡 그림이 아니라 '외친 단어와 일치하는지'만 보세요. 헷갈려 잘못 손을 얹으면 카드를 받습니다.

🫘 Bohnanza 콩심기 / 보난자

👥 2~7인⏱️ 약 45분🎯 보통
🎯 목표콩을 심고 수확해 가장 많은 금화를 벌기.
🔄 진행 방식
  1. 손패는 순서를 절대 바꿀 수 없다(핵심 규칙).
  2. 맨 앞 콩 1~2장을 밭에 심고, 덱에서 뽑은 콩은 다른 사람과 자유롭게 거래·기부한다.
  3. 같은 종류 콩을 많이 모아 밭째 수확하면 개수에 따라 금화를 받는다.
🏆 승리 조건게임 종료 시 모은 금화가 가장 많은 사람이 승리.
💡 안 맞는 콩은 쌓아두지 말고 적극적으로 거래하세요. 밭은 보통 2칸뿐이라 관리가 관건.

🎭 Liar Game 라이어 게임

👥 3~12인⏱️ 약 15분🎯 쉬움
🎯 목표시민은 라이어를 찾고, 라이어는 제시어를 모른 채 들키지 않기.
🔄 진행 방식
  1. 한 명만 라이어로 뽑히고, 라이어를 뺀 전원이 같은 제시어를 본다.
  2. 돌아가며 제시어에 대한 힌트를 한마디씩 말한다(너무 대놓고 말하면 라이어에게 정답 노출).
  3. 토론 후 다 같이 라이어로 의심되는 사람을 지목·투표.
🏆 승리 조건라이어를 맞히면 시민 승, 못 맞히거나 라이어가 제시어를 맞히면 라이어 승.
💡 아는 사람만 알아들을 만큼 애매하게 말하는 게 실력. 라이어라면 남의 말에 얹어가며 아는 척하세요.

🕵️ Who Am I? 인물 맞추기

👥 2인 이상⏱️ 약 15분🎯 쉬움
🎯 목표내 이마에 붙은 카드 속 인물·사물이 무엇인지 질문으로 알아내기.
🔄 진행 방식
  1. 자기 카드는 못 보게 이마(또는 머리띠)에 붙인다.
  2. 돌아가며 "예/아니오"로 답할 수 있는 질문을 던진다("나는 사람인가요?").
  3. '예'가 나오면 한 번 더 질문, '아니오'면 다음 사람에게 차례가 넘어간다.
🏆 승리 조건자기 정답을 가장 먼저 맞힌 사람이 승리.
💡 큰 범주부터 좁혀가세요(생물→사람→실존→성별…). 초반부터 콕 집어 찍으면 손해.

🔔 Pit 피트

👥 3~8인⏱️ 약 30분🎯 쉬움
🎯 목표한 가지 상품(콩·밀·옥수수 등) 카드를 9장 모두 모으기.
🔄 진행 방식
  1. 모두 동시에 진행 — 필요 없는 같은 종류 카드 1~4장을 "1장! 2장!" 외치며 아무하고나 맞교환한다.
  2. 장수만 외치고 어떤 상품인지는 밝히지 않는다.
  3. 한 종류를 다 모으면 종을 울리며 "코너(Corner)!"를 외친다.
🏆 승리 조건매점에 성공하면 해당 상품 점수를 얻고, 정해진 점수에 먼저 도달하면 최종 승리.
💡 시끄러운 게 정상입니다. 망설이지 말고 큰 소리로 계속 교환을 시도하세요.

🐂 Take 5 6 Nimmt! / 6 니름

👥 2~10인⏱️ 약 45분🎯 보통
🎯 목표소머리(벌점) 토큰을 최대한 적게 먹기.
🔄 진행 방식
  1. 모두 카드 1장을 동시에 고른 뒤 함께 공개한다.
  2. 낮은 숫자부터, 4개의 줄 중 '자기 숫자보다 작으면서 가장 가까운' 줄 끝에 놓는다.
  3. 놓는 카드가 줄의 6번째가 되면 앞 5장을 벌점으로 가져오고, 그 카드가 새 줄의 시작이 된다.
🏆 승리 조건정해진 라운드 후 소머리 벌점이 가장 적은 사람이 승리.
💡 남들이 낼 숫자를 예측해 '6번째'를 떠안지 마세요. 아주 낮은 카드는 위험 회피용으로 유용.

🏝️ Catan 카탄

👥 3~4인⏱️ 약 75분🎯 보통
🎯 목표개척지·도시·발전카드로 가장 먼저 승점 10점 모으기.
🔄 진행 방식
  1. 내 차례에 주사위 2개를 굴리면, 그 숫자가 적힌 땅에 접한 모두가 자원(나무·흙·양·밀·돌)을 얻는다.
  2. 자원을 조합해 길·개척지(1점)·도시(2점)를 짓거나 발전카드를 산다.
  3. 자원은 자유롭게 거래, 7이 나오면 도둑이 이동하고 자원을 뺏는다.
🏆 승리 조건가장 먼저 승점 10점에 도달한 사람이 승리.
💡 첫 개척지 위치가 게임을 좌우합니다. 자주 나오는 숫자(6·8)와 항구를 노리세요.

🔍 Clue 클루 / Cluedo

👥 2~6인⏱️ 약 45분🎯 보통
🎯 목표누가·어디서·무엇으로 살인했는지 세 가지를 먼저 밝혀내기.
🔄 진행 방식
  1. 범인·장소·흉기 카드 각 1장을 봉투에 숨기고 나머지를 나눠 갖는다.
  2. 말을 옮겨 방에 들어가 "○○이 △△방에서 □□로"라고 추리를 제시한다.
  3. 다음 사람부터 그 카드 중 하나를 갖고 있으면 나에게만 몰래 보여줘 반증한다.
🏆 승리 조건봉투 속 정답 3장을 정확히 지목한 사람이 승리(틀리면 탈락).
💡 반증에 쓰인 카드를 표에 꼼꼼히 기록하세요. 일부러 내 카드를 넣어 물으면 상대를 교란할 수 있습니다.

🐫 Camel Up 카멜 업 🆕 신규

👥 3~8인⏱️ 약 25분🎯 쉬움
🎯 목표낙타 경주에 베팅해 가장 많은 돈을 벌기.
🔄 진행 방식
  1. 피라미드에서 주사위를 뽑아 해당 색 낙타를 전진시킨다(낙타는 서로 위에 올라타 함께 이동).
  2. 한 '구간(leg)'의 1·2등을 예상해 베팅 티켓을 가져가거나, 전체 우승/꼴찌를 예측해 몰래 베팅한다.
  3. 주사위가 다 나오면 구간이 끝나고 순위대로 정산.
🏆 승리 조건경주 종료 시 모은 돈이 가장 많은 사람이 승리.
💡 일찍 베팅할수록 배당이 큽니다. 낙타가 쌓이는 위치를 잘 보고 눈치껏 먼저 거세요.

🧋 Sabobatage 보바 카드게임 🆕 신규

👥 2~5인⏱️ 10~30분🎯 쉬움
🎯 목표보바(버블티) 가게 사장이 되어 음료 세트 5개를 먼저 완성하기.
🔄 진행 방식
  1. 내 차례에 카드 2장을 뽑는다(완성 세트가 2개 이상이면 3장).
  2. 카드를 최대 3장까지 내서 재료로 음료 세트를 만들거나, 도움 카드를 쓰거나, 상대를 방해(사보타지)한다.
  3. 진행 중 세트는 최대 7개, 손패는 차례 종료 시 7장 이하로 유지한다.
🏆 승리 조건음료 세트 5개를 먼저 완성한 사람이 승리(위생검사관 카드는 조심!).
💡 완성 세트 2개를 빨리 만들면 매 턴 3장씩 뽑아 크게 유리해집니다. 상대 방해와 내 완성 속도의 균형이 핵심.

게임 가이드

🏆 Tier Points

게임 실력을 나타내는 점수입니다. 리더보드 순위는 이 점수로 결정됩니다.

  • 계산: 누적 승점 + 누적 감점 (감점은 음수)
  • 음수 가능 — 감점이 많으면 마이너스로 표시
  • 출석 보너스 / 사용한 포인트 / 교환은 영향 없음

🎁 Reward Points

상품과 교환할 수 있는 지갑 포인트입니다.

  • 계산: Tier Points + 출석 보너스 − 사용한 포인트 − 교환
  • 최소 0 — 음수가 되면 0으로 표시
  • 교환해도 순위 안 떨어집니다 (Tier만 순위에 반영)

📅 출석 보너스

모임 참여 시 받는 추가 포인트입니다.

  • 출석 체크 / HSM Running Club 행이 해당
  • 게임 통계 (게임 수, 승률)에 포함되지 않음
  • Reward Points에만 가산

📋 리더보드 정렬 기준

동률 시 아래 순서로 비교합니다.

  1. Tier Points (높을수록 유리)
  2. 총 승점
  3. 승리 횟수
  4. 게임 수
  5. 총 감점 (적을수록 유리)

🎖️ 메달 / 배지 의미

  • 1 1위 (승점 보유 시)
  • 2 2위
  • 3 3위
  • N-1 5명 이상일 때 꼴찌 직전
  • N 4명 이상일 때 꼴찌
  • 🟥 감점 발생 (히스토리)
  • ➖ 점수 변동 없음 (히스토리)

📈 순위 변화 차트

각 모임 시점까지의 누적 Tier Points로 산정한 순위 변화입니다.

  • 가장 오른쪽 점이 현재 순위
  • 우측 드롭다운에서 표시할 플레이어 선택
  • "전체 선택" 토글로 한 번에 켜고 끄기

🔄 데이터 업데이트

  • Google Sheets 수정 → Apps Script 실행 → 자동으로 GitHub 업로드
  • 페이지 우측 상단 새로고침 버튼으로 최신 데이터 즉시 로드
  • "업데이트 ◯◯" 표시는 GitHub 파일의 마지막 수정 시각

  • 최대 10MB, .xlsx / .xls 만 허용

🛡️ 보안

  • CSP (Content Security Policy): 외부 스크립트는 jsDelivr CDN만 허용
  • SRI (Subresource Integrity): CDN 파일이 변조되면 자동 차단
  • 업로드 비밀번호는 SHA-256 해시로만 저장 (평문 X)
  • 업로드 파일 검증: 확장자 + 10MB 제한 + 매크로/수식 비활성
